## About Makerpanel

Makerpanel is inspired by the Eurotrack synthesizer module standard but reimagined for general maker applications. By using negative space rails with M5/M6 twist nuts normally used for t-slots, panels can be easily mounted, rearranged, and customized without permanent modifications.

Whether you're building a control interface for your CNC machine, creating a custom MIDI controller, or designing a home automation panel, or Cyberdeck - Makerpanel provides the framework for modular, professional-looking results.
