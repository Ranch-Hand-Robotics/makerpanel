# LilyGo 4.7-inch S3 Display Panel

[lilygo_screen.scad](lilygo_screen.scad) provides the panel and reference
geometry for positioning the display and rear electronics.

## Customization

- Set `horizontalPitch` and `verticalUnits` for the panel size.
- Adjust `ribbon_cutout_w` and `ribbon_cutout_h` for the cable opening.
- Use `ribbon_cutout_offset_x` and `ribbon_cutout_offset_y` to position it.

Verify the display revision, attachment method, ribbon bend radius, and rear
clearance against your hardware before fabrication.
