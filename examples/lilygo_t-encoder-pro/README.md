# LilyGo T-Encoder Pro Panel

[design/lilygo_t-encoder-pro.scad](design/lilygo_t-encoder-pro.scad) creates
an extruded panel with a central circular encoder opening.

## Customization

- Set `horizontalPitch` and `verticalUnits` for the panel size.
- Review `lilygo_radius` against your encoder housing.
- Review `panel_depth` for the intended material and mounting method.

Keep the MakerPanel library available to the renderer. Confirm housing fit,
PCB clearance, and how the encoder will be secured before fabrication.
