# Prime79 Keyboard Panel

The source is named [prime97_panel.scad](prime97_panel.scad), despite the
`prime79_panel` folder name. It uses the Prime79 DXF outline for its keyboard
opening.

## Customization

- Set `horizontalPitch` and `verticalUnits` to size the surrounding panel.
- Review the `keyboard_cutout` reference and keep its DXF asset available.
- Inspect the flat and extruded variants before exporting for fabrication.

Confirm the outline against the intended keyboard, PCB, and mounting method.
The source and folder naming difference is retained rather than silently
renaming design assets.
