# Mouse Pad Panel

[MousePadPanel.scad](MousePadPanel.scad) provides a plain mouse pad support
surface with MakerPanel mounting geometry, without component cutouts.

## Customization

- Set `horizontalPitch` and `verticalUnits` to fit the available space.
- Review `mousepad_panel_depth` for the intended panel material.
- Use the design's flat or extruded geometry for cutting or printing.

Allow clearance for mounting hardware and select a suitable mouse pad or
surface finish. Confirm panel stiffness for the chosen span and material.
