Maker Panel 4 HP Template

Modular maker panel for control electronics - 4 HP x 3U size

Specifications

Width
4 HP = 20.32 mm
Height
3U = 128.5 mm (standard)
Maximum Depth
60 mm from front face
Material
FR4 PCB 1.6 mm thickness
Mounting System
T-slot compatible with M5/M6 nuts
Mounting Holes
4 × 3 mm diameter (M3 screw clearance)

Use Case

Perfect for single control elements:

  • Single potentiometer
  • Single LED indicator
  • Minimal UI panels
  • Compact designs

Design Guidelines

  • ✓ Keep components within "Design Area" guides (silkscreen)
  • ✓ Maintain 2 mm minimum clearance from edges
  • ✓ Keep copper 3 mm away from mounting holes (M1-M4)
  • ✓ Maximum depth 60 mm total
  • ✓ Use 5.08 mm grid (1 HP) for alignment

Compliance

This template is fully compliant with Maker Panel Specification v1.0

  • ✓ Width in HP units (1 HP = 5.08 mm)
  • ✓ T-slot compatible mounting
  • ✓ Standard 3U height (128.5 mm)
  • ✓ Depth within 60 mm limit
  • ✓ Proper edge clearances
